# House Price Predictor using Machine Learning

A Python-based Supervised Machine Learning project that utilizes **Linear Regression** to estimate residential property prices based on features like bedrooms, bathrooms, and square footage.

## 🚀 Features
* **Data Preprocessing:** Cleans and structures data using `pandas`.
* **Predictive Modeling:** Implements `scikit-learn` Linear Regression to draw a mathematical best-fit line.
* **Robust Input Validation:** Includes custom exception handling blocks to prevent runtime crashes during user input.
* **Interactive Inference:** Features a built-in terminal function for real-time market value estimation.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-Learn
* **Environment:** Google Colab / Jupyter Notebook

## 📈 Model Performance Metrics
* **Mean Absolute Error (MAE):** Evaluates average price variance.
* **R-squared ($R^2$) Score:** Quantifies overall model accuracy and variance fit.

## 💻 How to Run
1. Clone this repository.
2. Open `House_Price_Predictor.ipynb` in Google Colab or Jupyter Notebook.
3. Run all cells sequentially to train the model and launch the interactive predictor tool.
